4.4 Studi Kasus JavaScript: Aplikasi Kalkulator Nilai Akhir

Panduan instruksi tugas serta contoh aplikasi perhitungan nilai siswa secara real-time.

STUDI KASUS: JAVASCRIPT

Deskripsi Tugas Membuat aplikasi web interaktif sederhana berupa Kalkulator Nilai Akhir Siswa yang menghitung nilai rata-rata dari Tugas, UTS, dan UAS secara otomatis menggunakan DOM Manipulation dan Event Handling JavaScript.

Instruksi Pengerjaan:

Buat halaman HTML dan script JavaScript yang memiliki fitur:

  1. Judul halaman menggunakan heading <h1> (Kalkulator Nilai Siswa).
  2. Formulir input angka untuk:
    • Nama Siswa (<input type="text">)
    • Nilai Tugas (<input type="number">)
    • Nilai UTS (<input type="number">)
    • Nilai UAS (<input type="number">)
  3. Tombol aksi (<button>) "Hitung Nilai".
  4. Event Listener saat tombol diklik untuk mengambil nilai input dan menghitung Rata-rata ((Tugas + UTS + UAS) / 3).
  5. Pengkondisian (if / else) penentu kelulusan:
    • Rata-rata ≥ 75: "LULUS"
    • Rata-rata < 75: "REMIDI"
  6. Validasi input kosong (tampilkan pesan error jika ada input tidak diisi).
  7. Tampilkan hasil kalkulasi (Nama, Rata-rata, Status Kelulusan) pada elemen HTML penampung output.
Catatan Pengerjaan:
  • Gunakan tag HTML dan JavaScript standar (internal script).
  • Gunakan e.preventDefault() jika menggunakan form agar halaman tidak reload.
  • Tidak harus sama persis dengan contoh, yang penting alur logika JavaScript berfungsi dengan baik.
