4.4 Studi Kasus JavaScript: Kalkulator Invoice Sederhana

Panduan instruksi tugas serta contoh kalkulasi total belanja secara otomatis dan real-time.

STUDI KASUS: JAVASCRIPT

Deskripsi Tugas Membuat aplikasi web sederhana untuk menghitung total tagihan belanja secara otomatis. Nilai total akan langsung muncul di layar saat pengguna memasukkan Harga Barang dan Jumlah Beli menggunakan DOM Manipulation dan Event Handling JavaScript.

Instruksi Pengerjaan:

Buat halaman HTML dan script JavaScript yang memiliki fitur:

  1. Judul halaman menggunakan heading <h1> (Kalkulator Invoice Sederhana).
  2. Formulir input data transaksi:
    • Nama Barang (<input type="text">)
    • Harga Barang (<input type="number">)
    • Jumlah Beli (<input type="number">)
  3. Event Handler (Gunakan event input) agar saat angka dimasukkan/diubah, hasil perhitungan langsung diproses secara otomatis.
  4. Rumus perhitungan sederhana: Total = Harga Barang × Jumlah Beli.
  5. Tampilkan hasil perhitungan total pada kolom output secara langsung.
Catatan Pengerjaan:
  • Gunakan event oninput pada tag input atau addEventListener('input') di JavaScript.
  • Tidak memerlukan tombol simpan atau cetak, fokus pada logika perkalian otomatis dua kolom input.
