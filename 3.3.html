Modul 03 • CSS Desain Web

3.3 Responsive Design & Media Query

Teknik merancang tampilan web agar adaptif dan nyaman diakses melalui berbagai ukuran layar perangkat.

01

Viewport Meta Tag & Fluid Layout

Pondasi utama web responsif dengan mengatur skala viewport mobile dan unit fleksibel seperti persentase.

viewport.html 
<meta name="viewport" content="width=device-width, initial-scale=1.0">

<div class="fluid-box">
  Elemen Fleksibel (Width %)
</div>
style.css 
.fluid-box {
  width: 100%;
  max-width: 600px;
  padding: 16px;
  background-color: #e0f2fe;
}
Hasil Tampilan Web
Elemen Fleksibel (Width 100%)

Konsep Dasar Web Responsif

  • Viewport Meta Tag: Mencegah layar perangkat seluler merender halaman dalam ukuran standar komputer secara otomatis.
  • Unit Persentase (%): Mengatur ukuran elemen secara dinamis mengikuti lebar wadah (*container*).
  • max-width: Membatasi lebar maksimum elemen agar tidak merenggang berlebihan pada layar lebar.
02

CSS Media Query (@media)

Penggunaan aturan @media untuk mengubah gaya CSS secara otomatis ketika lebar layar memenuhi kondisi (*breakpoint*) tertentu.

media.html 
<div class="kotak-responsif">
  Kondisi Layar
</div>
style.css 
.kotak-responsif {
  background-color: #fef3c7;
}

@media (min-width: 768px) {
  .kotak-responsif {
    background-color: #dcfce7;
  }
}
Hasil Tampilan Web
Desktop (≥ 768px): Hijau
Mobile (< 768px): Kuning

Prinsip Kerja Media Query

  • min-width: Menerapkan aturan CSS jika lebar viewport melebihi atau sama dengan batas piksel yang ditentukan.
  • max-width: Menerapkan aturan CSS hanya ketika lebar viewport kurang dari batas piksel tertentu.
  • Breakpoint Populer: 576px (HP), 768px (Tablet), dan 1024px (Desktop/Laptop).
03

Strategi Mobile-First Approach

Pendekatan modern dengan mendesain tampilan default untuk layar smartphone terlebih dahulu, kemudian menambahkan gaya untuk layar yang lebih lebar.

mobile-first.html 
<div class="grid-layout">
  <div class="item">1</div>
  <div class="item">2</div>
</div>
style.css 
/* Default Mobile: 1 Kolom */
.grid-layout {
  display: grid;
  grid-template-columns: 1fr;
}

/* Laptop/Desktop */
@media (min-width: 768px) {
  .grid-layout {
    grid-template-columns: 1fr 1fr;
  }
}
Hasil Tampilan Web
Kolom 1
Kolom 2

Keunggulan Mobile-First

  • Performa Lebih Cepat: Perangkat seluler hanya memuat kode standar tanpa memproses CSS desktop yang berat.
  • Kode Lebih Rapi: Menggunakan query min-width membuat struktur gaya bertambah secara bertahap (skalabel).
04

Studi Kasus: Layout Navigation Bar Responsif

Penerapan Media Query untuk menyusun menu navigasi horizontal pada desktop dan berubah menjadi menu tumpuk/tombol burger pada perangkat seluler.

navbar.html 
<nav class="navbar">
  <div class="logo">SMTI</div>
  <div class="menu">
    <a href="#">Beranda</a>
    <a href="#">Materi</a>
    <a href="#">Kontak</a>
  </div>
</nav>
style.css 
.navbar {
  display: flex;
  flex-direction: column;
  gap: 10px;
}

@media (min-width: 640px) {
  .navbar {
    flex-direction: row;
    justify-content: space-between;
    align-items: center;
  }
}
Hasil Tampilan Web
SMTI LOGO
Beranda Materi Kontak

Pembahasan Studi Kasus

  • Arah Flexbox Dinamis: Properti flex-direction diubah dari column (Mobile) menjadi row (Desktop) secara otomatis saat lebar layar melampaui 640px.
  • Efisiensi Ruang Layar: Elemen navigasi menyatu ke samping pada layar komputer dan menumpuk rapi pada layar smartphone agar mudah disentuh.
