Modul 02 • HTML

2.2 Table, Form, Input, & Button

Penyajian data terstruktur menggunakan tabel serta pengumpulan masukan pengguna dengan formulir interaktif.

01

Pembuatan Tabel Data (<table>)

Penggunaan struktur terpisah <thead> dan <tbody> untuk menyajikan data terstruktur dalam bentuk baris dan kolom.

tabel.html 
<table border="1">
  <thead>
    <tr>
      <th>No</th>
      <th>Nama</th>
      <th>Kelas</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>1</td>
      <td>Ahmad</td>
      <td>XI TM 1</td>
    </tr>
    <tr>
      <td>2</td>
      <td>Budi</td>
      <td>XI TM 2</td>
    </tr>
  </tbody>
</table>
http://localhost:5500/tabel.html
No Nama Kelas
1 Ahmad XI TM 1
2 Budi XI TM 2

Penjelasan Atribut Penggabungan Sel Tabel

  • colspan: Menggabungkan beberapa kolom secara mendatar (horizontal) pada sel tabel.
  • rowspan: Menggabungkan beberapa baris secara menurun (vertikal) pada sel tabel.
02

Formulir HTML (<form>)

Tag <form> bertindak sebagai wadah pembungkus komponen input untuk dikirimkan ke server backend.

form.html 
<form action="simpan.php" method="POST">
  <label for="username">Username:</label><br>
  <input type="text" id="username" name="username" placeholder="Masukkan username"><br><br>

  <button type="submit">Kirim</button>
</form>
http://localhost:5500/form.html

Penjelasan Atribut Utama Elemen Form

  • action: Menentukan URL/file tujuan pemrosesan data ketika form dikirimkan.
  • method: Metode pengiriman HTTP data, yaitu GET (data terlihat di URL) atau POST (data dikirim di balik layar secara aman).
  • name: Kunci identifikasi variabel data yang ditangkap oleh server.
03

Elemen Input (<input>) & Button (<button>)

Atribut type mendefinisikan bentuk serta jenis kontrol masukan data dari pengguna.

input.html 
<input type="text" placeholder="Nama Lengkap"><br><br>
<input type="password" placeholder="Kata Sandi"><br><br>

<input type="radio" name="gender" checked> Laki-laki
<input type="radio" name="gender"> Perempuan<br><br>

<input type="checkbox" checked> Saya menyetujui syarat & ketentuan<br><br>

<button type="submit">Simpan Data</button>
http://localhost:5500/input.html

Tipe-Tipe Input & Tombol

Tipe-Tipe Input
  • text: Isian teks satu baris biasa.
  • password: Teks tersembunyi berwujud bulatan/bintang.
  • radio: Memilih 1 opsi tunggal dari beberapa pilihan.
  • checkbox: Memilih beberapa opsi centang bersamaan.
Tipe Tombol (<button>)
  • submit: Mengirimkan seluruh isi form ke server.
  • reset: Mengosongkan/mengembalikan form ke keadaan awal.
  • button: Tombol netral untuk aksi script JavaScript.
04

Studi Kasus: Form Pendaftaran

Penggabungan pilihan dropdown (<select>), teks multi-baris (<textarea>), serta kontrol tombol ke dalam formulir pendaftaran.

pendaftaran.html 
<form>
  <label>Jurusan:</label><br>
  <select name="jurusan">
    <option>Teknik Mekatronika</option>
    <option>Teknik Kimia Industri</option>
  </select><br><br>

  <label>Alamat Lengkap:</label><br>
  <textarea rows="3" placeholder="Tuliskan alamat rumah..."></textarea><br><br>

  <button type="submit">Daftar Sekarang</button>
</form>
http://localhost:5500/pendaftaran.html

Komponen Pendukung Input HTML

  • <select> & <option>: Membuat daftar pilihan dropdown terisolasi tanpa memakan area layar yang luas.
  • <textarea>: Area pengisian teks multi-baris yang cocok digunakan untuk masukan alamat, pesan, atau catatan.
  • placeholder: Atribut pembantu yang menampilkan petunjuk samar sebelum pengguna mengetikkan isi input.
