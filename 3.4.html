3.4 CSS Animation & Transition (9 Efek Tombol)

Kumpulan teknik penerapan animasi dan transisi CSS murni khusus pada elemen Button.

01

1. Berubah Warna

Warna latar belakang tombol berubah secara halus dari biru menjadi ungu saat kursor diarahkan ke atasnya.

index.html
<button class="btn-color">Ubah Warna</button>
style.css
.btn-color {
  background-color: #0284c7;
  transition: background-color 0.4s ease;
}
.btn-color:hover {
  background-color: #8b5cf6;
}
Tampilan Web
02

2. Memantul (Bounce)

Menggunakan keyframe animasi untuk membuat efek memantul ke atas dan ke bawah.

index.html
<button class="btn-bounce">Memantul</button>
style.css
.btn-bounce:hover {
  animation: bounce 0.6s ease infinite alternate;
}
@keyframes bounce {
  0% { transform: translateY(0); }
  100% { transform: translateY(-10px); }
}

03

3. Miring 30°

Memutar sudut kemiringan posisi tombol sebesar 30 derajat menggunakan rotate().

index.html
<button class="btn-tilt">Miring 30°</button>
style.css
.btn-tilt {
  transition: transform 0.3s ease;
}
.btn-tilt:hover {
  transform: rotate(30deg);
}

4. Membesar (Zoom)

Meningkatkan skala ukuran tombol sebesar 15% menggunakan properti scale().

index.html
<button class="btn-zoom">Membesar</button>
style.css
.btn-zoom {
  transition: transform 0.3s ease;
}
.btn-zoom:hover {
  transform: scale(1.15);
}
Tampilan Web
05

5. Bergoyang (Shake)

Efek getaran/goyangan horizontal pada tombol saat di-hover.

index.html
<button class="btn-shake">Bergoyang</button>
style.css
.btn-shake:hover {
  animation: shake 0.4s ease-in-out infinite;
}
@keyframes shake {
  0%, 100% { transform: translateX(0); }
  25% { transform: translateX(-5px); }
  75% { transform: translateX(5px); }
}
Tampilan Web
06

6. Melayang & Glow

Tombol naik ke atas disertai efek bayangan bercahaya (box-shadow) yang lembut.

index.html
<button class="btn-glow">Melayang & Glow</button>
style.css
.btn-glow {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}
.btn-glow:hover {
  transform: translateY(-5px);
  box-shadow: 0 10px 20px rgba(99, 102, 241, 0.4);
}

07

7. Tekan Amblas

Efek 3D fisik di mana tombol terlihat amblas/tertekan ke dalam saat diklik (:active).

index.html
<button class="btn-press">Tekan Amblas</button>
style.css
.btn-press {
  box-shadow: 0 5px 0 #334155;
  transition: all 0.1s ease;
}
.btn-press:active {
  transform: translateY(4px);
  box-shadow: 0 1px 0 #334155;
}

08

8. Fill Background

Warna latar belakang menyapu dari sisi kiri ke kanan secara bertahap saat kursor disentuhkan.

index.html
<button class="btn-fill">Fill Background</button>
style.css
.btn-fill {
  position: relative; z-index: 1; overflow: hidden;
}
.btn-fill::before {
  content: '';
  position: absolute; top: 0; left: 0;
  width: 0%; height: 100%;
  background-color: #ec4899; z-index: -1;
  transition: width 0.4s ease;
}
.btn-fill:hover::before {
  width: 100%;
}
