01

Button Hover: Berubah Warna & Naik

Ketika kursor diarahkan ke tombol, tombol akan naik sedikit ke atas (translateY) dan berubah warna latar secara halus.

button.html
<button class="btn-custom">
  Simpan Data
</button>
style.css
.btn-custom {
  background-color: #0284c7;
  color: #ffffff;
  padding: 10px 20px;
  border: none;
  border-radius: 8px;
  transition: transform 0.3s, background-color 0.3s;
}
.btn-custom:hover {
  background-color: #0369a1;
  transform: translateY(-5px);
}

02

Card Gambar: Perbesar Gambar Saat Hover

Efek zoom-in pada gambar di dalam bingkai tanpa merusak batas luar bingkai (overflow: hidden).

image.html
<div class="img-card">
  <img src="pemandangan.jpg" alt="Demo">
</div>
style.css
.img-card {
  width: 180px;
  height: 110px;
  border-radius: 8px;
  overflow: hidden;
}
.img-card img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  transition: transform 0.4s ease;
}
.img-card:hover img {
  transform: scale(1.15);
}

03

Card Hover: Posisi Agak Miring

Memberikan orientasi kemiringan sudut (rotate) pada elemen kartu saat di-hover untuk menciptakan gaya UI yang dinamis.

card.html
<div class="tilt-card">
  <h4>Kartu Fitur</h4>
  <p>Sorot saya!</p>
</div>
style.css
.tilt-card {
  width: 160px;
  padding: 16px;
  background-color: #ffffff;
  border: 1px solid #cbd5e1;
  border-radius: 10px;
  text-align: center;
  transition: transform 0.3s ease;
}
.tilt-card:hover {
  transform: rotate(5deg) scale(1.02);
}

04

Bola Melompat-lompat (Bouncing Animation)

Animasi perulangan terus menerus (infinite) memanfaatkan titik keyframe CSS untuk menyimulasikan gravitasi gerak bola.

ball.html
<div class="ball-container">
  <div class="ball"></div>
</div>
style.css
.ball-container {
  height: 100px;
  display: flex;
  align-items: flex-end;
  justify-content: center;
}
.ball {
  width: 32px;
  height: 32px;
  background-color: #ef4444;
  border-radius: 50%;
  animation: bounce 0.8s infinite alternate ease-in;
}
@keyframes bounce {
  0% { transform: translateY(-60px); }
  100% { transform: translateY(0); }
}
