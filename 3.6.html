STUDI KASUS 2: STYLING LANDING PAGE PRODUK

Deskripsi Tugas Membuat dan menghias halaman Landing Page Produk / Katalog Penjualan Sederhana (misalnya: Produk Kedai Kopi, Merchandise Sekolah, atau Gadget) menggunakan aturan CSS agar memiliki tampilan visual modern, rapi, dan terstruktur.

Instruksi Pengerjaan:

Buatlah file CSS terpisah (style.css) atau gunakan tag <style> untuk mengatur elemen-elemen berikut:

  1. CSS Selectors & Typography: Atur jenis font (font-family), ukuran, warna teks, dan tingkat ketebalan (font-weight) pada judul serta deskripsi produk.
  2. Color Palette: Tentukan kombinasi warna latar belakang (background-color) dan warna aksen tombol/elemen yang harmonis.
  3. Box Model: Terapkan pengaturan jarak yang presisi menggunakan margin, padding, border, serta border-radius pada komponen kartu produk (card).
  4. Flexbox / Grid Layout: Susun tata letak komponen (*Navbar*, *Katalog Kartu Produk*, dan *Footer*) agar sejajar secara rapi.
  5. Pseudo-classes & Transition: Tambahkan efek interaktif saat kursor mengarah ke tombol beli atau kartu produk (:hover dan transition).
  6. Responsive Web Design: Gunakan media query (@media) agar tampilan layout katalog dapat menyesuaikan ukuran layar perangkat (HP & Laptop).
Catatan Pengerjaan:
  • Bebas menentukan jenis produk yang ingin dipromosikan.
  • Utamakan kerapian struktur pemanggilan CSS (*clean code* & konsistensi variabel warna).
  • Gunakan inspect element pada browser untuk membantu *debugging* aturan CSS Box Model.
