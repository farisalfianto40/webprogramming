2.3 Semantic HTML & Pengelompokan Elemen

Penyusunan tata letak halaman web yang terstruktur menggunakan tag semantik serta pengelompokan elemen dengan Div, Class, dan ID.

01

Struktur Halaman Semantik (<header>, <nav>, <main>, <footer>)

Penggunaan tag semantik memberikan makna yang jelas pada struktur web sehingga mempermudah pembacaan oleh mesin pencari (SEO) dan *browser*.

semantic.html 
<header>
  <h1>Portal Belajar</h1>
</header>

<nav>
  <a href="#">Beranda</a> | <a href="#">Materi</a>
</nav>

<main>
  <h2>Selamat Datang</h2>
  <p>Ini adalah konten utama halaman.</p>
</main>

<footer>
  <p>&copy; 2026 SMK SMTI Yogyakarta</p>
</footer>
http://localhost:5500/semantic.html

Portal Belajar

Beranda | Materi

Selamat Datang

Ini adalah konten utama halaman.

© 2026 SMK SMTI Yogyakarta

Penjelasan Tag Semantik Utama

  • <header>: Menyimpan area kepala halaman seperti judul situs, logo, atau banner utama.
  • <nav>: Wadah khusus yang berisi kumpulan menu navigasi atau tautan antarhalaman.
  • <main>: Menyimpan seluruh konten paling penting dan unik dari sebuah halaman web.
  • <footer>: Area kaki halaman yang berisi informasi hak cipta, kontak, atau tautan tambahan.
02

Pengelompokan Elemen (<div> & <span>)

<div> digunakan untuk mengelompokkan elemen *block*, sedangkan <span> digunakan untuk bagian teks secara *inline*.

container.html 
<div>
  <h3>Pengumuman</h3>
  <p>Status sistem: <span>Aktif</span></p>
</div>
http://localhost:5500/container.html

Pengumuman

Status sistem: Aktif

Penjelasan Pengelompokan Elemen

  • <div>: Elemen *block-level* tanpa makna khusus yang berfungsi sebagai kontainer/wadah pembungkus komponen.
  • <span>: Elemen *inline* yang digunakan untuk menyeleksi atau memberi gaya pada bagian kata/teks tertentu.
03

Atribut Identifikasi (Class & ID)

Atribut class digunakan untuk penamaan elemen secara berulang, sedangkan id bersifat unik khusus untuk satu elemen saja.

class-id.html 
<div id="header-utama">
  <h2 class="judul">Modul Pembelajaran</h2>
</div>

<div class="kartu">
  <p>Materi HTML 5</p>
</div>
<div class="kartu">
  <p>Materi CSS 3</p>
</div>
http://localhost:5500/class-id.html

Modul Pembelajaran

Materi HTML 5
Materi CSS 3

Perbedaan Class dan ID

  • class: Penanda kelompok yang dapat dipakai berulang kali pada banyak elemen berbeda sekaligus.
  • id: Pengenal unik tunggal yang hanya boleh digunakan oleh satu elemen saja dalam satu halaman HTML.
