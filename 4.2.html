4.2 DOM Manipulation, Event Handling, Validasi Form, & localStorage

Penguasaan manipulasi struktur elemen web, penanganan interaksi pengguna, validasi data masukan, serta penyimpanan data lokal pada peramban web.

01

DOM Manipulation

Document Object Model (DOM) merupakan antarmuka pemrograman yang memungkinkan JavaScript untuk mengakses serta mengubah konten teks elemen HTML secara dinamik.

dom-basic.html 
<h1 id="judul"></h1>

<script>
  // Seleksi elemen berdasarkan ID
  const elJudul = document.getElementById('judul');

  // Mengubah isi teks elemen
  elJudul.textContent = 'Halo saya Budi';
</script>
http://localhost:5500/dom-basic.html

Halo saya Budi

Penjelasan Metode Seleksi & Manipulasi

  • document.getElementById('judul'): Mengambil referensi elemen DOM berdasarkan atribut id="judul".
  • textContent = 'Halo saya Budi': Memperbarui isi teks elemen <h1> secara langsung.
02

DOM Manipulation & Event Handling

Kombinasi manipulasi DOM dengan penanganan peristiwa (Event Handling) membuat halaman web merespons interaksi pengguna secara langsung saat tombol diklik.

dom-event.html 
<button id="btnYa">Ya</button>
<button id="btnTidak">Tidak</button>
<p>Status siswa: <span id="statusHasil"></span></p>

<script>
  const btnYa = document.getElementById('btnYa');
  const btnTidak = document.getElementById('btnTidak');
  const hasil = document.getElementById('statusHasil');

  btnYa.addEventListener('click', () => {
    hasil.textContent = 'Lulus';
  });

  btnTidak.addEventListener('click', () => {
    hasil.textContent = 'Tidak Lulus';
  });
</script>
http://localhost:5500/dom-event.html

Status siswa:

Penjelasan Event Listener

  • document.getElementById('statusHasil'): Mengambil target elemen <span> yang berada di dalam paragraf.
  • textContent = 'Lulus' / 'Tidak Lulus': Memperbarui isi dari elemen <span> secara spesifik tanpa mengubah teks statis "Status siswa: ".
03

Validasi Form Client-Side

Pemeriksaan data pada formulir (<form>) sebelum dikirimkan guna memastikan isian memenuhi kriteria kualifikasi serta menghentikan aksi default submit.

validasi.html 
<form id="saranForm">
  <label>Kritik / Saran:</label><br>
  <input type="text" id="pesanSaran">
  <button type="submit">Kirim</button>
</form>
<p id="statusForm"></p>

<script>
  document.getElementById('saranForm').addEventListener('submit', (e) => {
    e.preventDefault();
    const input = document.getElementById('pesanSaran').value;
    const status = document.getElementById('statusForm');

    if (input.trim() === '') {
      status.textContent = 'Kritik / saran wajib diisi!';
    } else {
      status.textContent = 'berhasil dikirim';
    }
  });
</script>
http://localhost:5500/validasi.html

Penjelasan Mekanisme Validasi

  • e.preventDefault(): Mencegah alur perilaku default peramban yang akan memuat ulang (refresh) halaman saat tombol submit ditekan.
  • input.trim() === '': Memeriksa apakah masukan teks dalam kondisi kosong atau hanya berisi spasi.
  • Pesan Output: Menampilkan pesan kesalahan jika masukan kosong, atau merespons dengan tulisan "berhasil dikirim" saat masukan valid.
04

Penyimpanan Lokal (<localStorage>)

localStorage menyimpan data berpasangan kunci-nilai (key-value) langsung pada browser klien tanpa memiliki masa kedaluwarsa saat halaman ditutup.

storage.html 
<input type="text" id="inputData" placeholder="Ketik data tersimpan...">
<button id="btnSimpan">Simpan</button>
<button id="btnHapus">Hapus</button>

<p>Nilai tersimpan: <span id="tampilData">(Belum ada data)></span></p>

<script>
  const inputData = document.getElementById('inputData');
  const btnSimpan = document.getElementById('btnSimpan');
  const btnHapus = document.getElementById('btnHapus');
  const tampilData = document.getElementById('tampilData');

  btnSimpan.addEventListener('click', () => {
    localStorage.setItem('dataKu', inputData.value);
    tampilData.textContent = inputData.value;
  });

  btnHapus.addEventListener('click', () => {
    localStorage.removeItem('dataKu');
    tampilData.textContent = '(Belum ada data)';
  });
</script>
http://localhost:5500/storage.html

Nilai tersimpan: (Belum ada data)

Penjelasan Mekanisme LocalStorage

  • localStorage.setItem('dataKu', nilai): Menyimpan teks dari input ke dalam memori peramban dengan kunci 'dataKu'.
  • localStorage.removeItem('dataKu'): Menghapus data dengan kunci 'dataKu' dari memori peramban.
  • Data yang tersimpan akan tetap ada meskipun halaman direfresh atau browser ditutup sampai tombol Hapus ditekan.

Studi Kasus: Aplikasi Pengingat Tugas (To-Do List Persistent)

Integrasi komprehensif antara manipulasi elemen DOM, penanganan event pemicu, validasi masukan kosong, serta penyimpanan data dinamis menggunakan localStorage.

todo.html 
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Daftar Tugas Praktikum</title>
  <style>
    /* Styling Dasar Murni */
    body { font-family: Arial, sans-serif; padding: 20px; }
    input { padding: 6px; margin-right: 5px; }
    button { padding: 6px 12px; cursor: pointer; }
    ul { list-style-type: none; padding: 0; margin-top: 15px; }
    li {
      background-color: #f1f5f9;
      padding: 8px 12px;
      margin-bottom: 6px;
      border-radius: 4px;
      display: flex;
      justify-content: space-between;
      align-items: center;
      gap: 10px;
    }
    li span {
      word-break: break-all;
    }
    .btn-hapus {
      color: #e11d48;
      background: none;
      border: none;
      font-weight: bold;
      cursor: pointer;
      flex-shrink: 0;
    }
  </style>
</head>
<body>

  <h1>Daftar Tugas Praktikum</h1>

  <input type="text" id="todoInput" placeholder="Tambah tugas baru...">
  <button onclick="tambahTugas()">Tambah</button>

  <ul id="todoList"></ul>

<script>
  let tugas = JSON.parse(localStorage.getItem('tugasList')) || [];

  function renderTugas() {
    const list = document.getElementById('todoList');
    list.innerHTML = '';
    tugas.forEach((item, index) => {
      list.innerHTML += `
        <li>
          <span>${item}</span>
          <button onclick="hapusTugas(${index})" class="btn-hapus">Hapus</button>
        </li>
      `;
    });
    localStorage.setItem('tugasList', JSON.stringify(tugas));
  }

  function tambahTugas() {
    const input = document.getElementById('todoInput');
    if (input.value.trim() === '') return alert('Isi tugas!');
    tugas.push(input.value);
    input.value = '';
    renderTugas();
  }

  function hapusTugas(index) {
    tugas.splice(index, 1);
    renderTugas();
  }

  renderTugas();
</script>
</body>
</html>
http://localhost:5500/todo.html
