3.1 CSS Dasar (Selector, Color, Font, & Box Model)

Pengenalan aturan seleksi elemen, pewarnaan, tipografi, serta konsep tata letak Box Model pada CSS.

01

CSS Selector (Tag, Class, & ID)

Selector digunakan untuk memilih elemen HTML yang ingin diberi gaya visual.

selector.html 
<h1 id="judul-utama">
  Judul Utama
</h1>

<div class="kartu">
  <p>Ini isi kartu.</p>
</div>
style.css 
#judul-utama {
  color: #0284c7;
  text-transform: uppercase;
}

.kartu {
  background-color: #f1f5f9;
  padding: 12px;
}
Hasil Tampilan Web

Judul Utama

Ini isi kartu.

Jenis-Jenis Selector Utama

  • Tag Selector: Menargetkan elemen HTML berdasarkan nama tag-nya (contoh: h1, p).
  • Class Selector: Menargetkan elemen menggunakan simbol titik (.kartu).
  • ID Selector: Menargetkan satu elemen unik menggunakan simbol pagar (#judul-utama).
02

Pewarnaan & Tipografi (Color & Font)

Pengaturan warna teks, latar belakang, jenis huruf, ukuran, serta ketebalan font pada dokumen.

font.html 
<div class="teks-kustom">
  Teks dengan Custom 
  Font & Color
</div>
style.css 
.teks-kustom {
  color: #4f46e5;
  background-color: #e0e7ff;
  font-family: 'Plus Jakarta Sans';
  font-size: 14px;
  font-weight: 700;
}
Hasil Tampilan Web
Teks dengan Custom Font & Color

Penjelasan Properti Color & Font

  • color & background-color: Menentukan warna teks dan latar belakang (Hex code / RGB).
  • font-family: Mengatur jenis tipe huruf yang dipakai.
  • font-size & font-weight: Menentukan ukuran dan ketebalan huruf.
03

CSS Box Model (Margin, Padding, Border)

Konsep dasar yang membungkus setiap elemen HTML dalam bentuk kotak yang terdiri dari Content, Padding, Border, dan Margin.

box-model.html 
<div class="box">
  Area Content
</div>
style.css 
.box {
  padding: 15px;
  border: 2px solid #0284c7;
  margin: 10px;
  box-sizing: border-box;
}
Hasil Tampilan Web
MARGIN (10px)
BORDER (2px)
PADDING (15px)
CONTENT

Komponen Utama Box Model

  • Content: Area utama tempat teks atau media berada.
  • Padding: Jarak dalam antara area konten dengan garis tepi (*border*).
  • Border: Garis tepi yang mengelilingi *padding* dan *content*.
  • Margin: Jarak luar yang memisahkan elemen dari elemen disekitarnya.
04

Studi Kasus: Kartu Profil Komponen

Penggabungan seluruh materi (Selector, Warna, Font, Margin, Padding, dan Border) dalam pembuatan kartu profil.

profil.html 
<div class="profile-card">
  <img src="foto.jpg" class="foto" alt="Foto Profil" />
  <h2 id="nama">Ahmad Prasetyo</h2>
  <p class="penjelasan">
    Siswa SMK SMTI Yogyakarta jurusan Teknik Mekatronika.
  </p>
</div>
style.css 
.profile-card {
  padding: 20px;
  border: 1px solid #cbd5e1;
  border-radius: 12px;
  text-align: center;
  background: #ffffff;
}

.foto {
  width: 64px;
  height: 64px;
  border-radius: 50%;
  margin-bottom: 12px;
}

#nama {
  font-size: 16px;
  color: #0f172a;
  margin-bottom: 6px;
}

.penjelasan {
  font-size: 13px;
  color: #64748b;
  line-height: 1.4;
}

Penjelasan Ringkas CSS

  • Foto Lingkaran: Properti border-radius: 50% mengubah gambar persegi menjadi lingkaran sempurna.
  • Pemberian Jarak: Penggunaan margin-bottom mengatur jarak bawah secara rapi antarelemen (foto, nama, dan penjelasan).
