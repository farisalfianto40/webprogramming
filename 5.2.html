5.2 Bootstrap 5: Komponen UI Utama (Navbar & Card)

Pembentukan struktur navigasi company profile serta pembuatan kartu layanan interaktif berbasis Bootstrap 5.

01

Navbar Company Profile Responsif (Bootstrap 5)

Navbar Bootstrap 5 menyediakan struktur navigasi siap pakai. Menggunakan class navbar, navbar-expand-lg, dan navbar-toggler untuk membuat menu responsif dengan dukungan JavaScript collapse bawaan Bootstrap.

navbar.html 
<nav class="navbar navbar-expand-lg navbar-light bg-white border rounded-3 p-2 shadow-sm">
  <div class="container-fluid">
    <a class="navbar-brand fw-bold text-primary fs-6" href="#">
      <i class="bi bi-airplane-fill"></i> TechCorp
    </a>
    <button class="navbar-toggler btn-sm" type="button" data-bs-toggle="collapse" data-bs-target="#navMenu">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="navMenu">
      <ul class="navbar-nav ms-auto mb-2 mb-lg-0 fs-7">
        <li class="nav-item"><a class="nav-link active fw-bold text-primary" href="#">Beranda</a></li>
        <li class="nav-item"><a class="nav-link" href="#">Layanan</a></li>
        <li class="nav-item"><a class="nav-link" href="#">Kontak</a></li>
      </ul>
    </div>
  </div>
</nav>

Penjelasan Class Bootstrap Navbar

  • navbar-expand-lg: Menentukan batas breakpoint di mana navigasi beralih dari tampilan terlipat (hamburger menu) ke tampilan menu horizontal penuh (layar Large/992px ke atas).
  • navbar-toggler & data-bs-toggle="collapse": Atribut JavaScript bawaan Bootstrap untuk membuka dan menutup menu dropdown pada layar mobile secara otomatis tanpa penulisan script manual.
  • ms-auto: Memanfaatkan Utility Margin (margin-left: auto) untuk mendororng deretan link navigasi ke sisi paling kanan.

Komponen Utama Bootstrap Card

Komponen kartu Bootstrap dibangun fleksibel dengan elemen struktur: card-body (ruang konten utama), card-title (penataan judul kartu), card-text (formatting paragraf penjelas), serta dukungan class warna kontekstual seperti bg-primary-subtle.

Analisis Responsif Grid Bootstrap

Menggunakan pola class col-12 col-sm-6 di dalam kontainer row membuat kartu profil layanan otomatis memakan 12 kolom penuh (1 kolom tumpuk) pada layar ponsel (Mobile) dan membagi rata menjadi 6 kolom per kartu (2 kolom) pada layar berukuran Small (SM / 576px) ke atas. Class h-100 memastikan tinggi kartu sejajar sama tinggi.
