4.1 Dasar Pemrograman JavaScript

Panduan dasar logika pemrograman web: Variabel, Tipe Data, Kondisional (if/else), Perulangan (Loop), Fungsi, dan Objek.

01

Variable & Tipe Data

Variabel adalah tempat untuk menyimpan data. Gunakan let jika nilainya bisa berubah, dan const jika nilainya tetap.

variabel.js 
let nama = "Budi";       // Teks (String)
const umur = 17;        // Angka (Number)
let lulus = true;      // True/False (Boolean)

console.log("Nama:", nama);
console.log("Umur:", umur);
console.log("Status Lulus:", lulus);
Console Output

> Nama: Budi

> Umur: 17

> Status Lulus: true

Catatan Penting:

  • String: Penulisan teks harus diapit tanda petik ("...").
  • Number: Penulisan angka langsung tanpa tanda petik.
  • Boolean: Hanya bernilai true (benar) atau false (salah).
02

Pengkondisional (if / else if / else)

Digunakan untuk membuat keputusan dengan beberapa tingkat pengujian. Jika syarat pertama tidak terpenuhi, program akan mengecek syarat berikutnya sebelum menentukan tindakan akhir.

kondisi.js 
let nilai = 80;

if (nilai >= 85) {
    console.log("Predikat A: Sangat Memuaskan");
} else if (nilai >= 75) {
    console.log("Predikat B: Memuaskan");
} else {
    console.log("Predikat C: Remidi");
}
Console Output

> Predikat B: Memuaskan

Catatan Penting:

  • Kondisi 1 (if): Mengecek apakah nilai ≥ 85.
  • Kondisi 2 (else if): Jika kondisi 1 salah, cek apakah nilai ≥ 75.
  • Kondisi 3 (else): Jika seluruh kondisi di atas tidak terpenuhi (< 75), opsi terakhir ini yang dieksekusi.
03

Perulangan (Loop)

Digunakan untuk memproses sekumpulan data (array) secara otomatis. Pada contoh ini, perulangan menampilkan seluruh daftar nama siswa satu per satu.

perulangan.js 
const daftarSiswa = ["Ahmad", "Budi", "Cici", "Deni"];

for (let i = 0; i < daftarSiswa.length; i++) {
    console.log("Siswa: " + daftarSiswa[i]);
}
Console Output

> Siswa: Ahmad

> Siswa: Budi

> Siswa: Cici

> Siswa: Deni

Penjelasan Struktur Kode:

  • let i = 0: Indeks array di JavaScript selalu dimulai dari angka 0.
  • i < daftarSiswa.length: Perulangan berjalan sampai batas jumlah elemen array (4 item).
  • daftarSiswa[i]: Mengakses nama siswa berdasarkan posisi indeks perulangan saat itu.
04

Function (Fungsi)

Fungsi seperti alat hitung/mesin. Kita membuat rumus hitung sekali, lalu bisa kita panggil berulang kali dengan angka yang berbeda.

fungsi.js 
// 1. Fungsi Penjumlahan
function tambah(a, b) {
    return a + b;
}

// 2. Fungsi Pengurangan
function kurang(a, b) {
    return a - b;
}

// Memanggil dan menampilkan hasil hitung
console.log("Hasil Penjumlahan:", tambah(10, 5));
console.log("Hasil Pengurangan:", kurang(10, 4));
Console Output

> Hasil Penjumlahan: 15

> Hasil Pengurangan: 6

Catatan Penting:

  • a, b adalah **Parameter** (variabel penampung angka yang dimasukkan).
  • Perintah return berfungsi mengembalikan nilai hasil perhitungan operasi matematika ke luar fungsi.
05

Object (Objek)

Objek digunakan untuk menyimpan beberapa data sekaligus yang berhubungan dalam satu variabel.

objek.js 
const siswa = {
    nama: "Budi",
    kelas: "XI TM",
    umur: 17
};

// Cara mengambil data di dalam objek
console.log("Nama Siswa:", siswa.nama);
console.log("Kelas:", siswa.kelas);
Console Output

> Nama Siswa: Budi

> Kelas: XI TM

Catatan Penting:

  • Objek dibuka dan ditutup dengan kurung kurawa { }.
  • Gunakan titik (.) untuk mengakses isi data di dalamnya (contoh: siswa.nama).
06

Studi Kasus: Cek Nilai Kelulusan

Penggabungan seluruh materi dasar (Variable, Function, dan Logic if/else) menjadi satu alur program sederhana.

studi-kasus.js 
// 1. Fungsi penentu status kelulusan
function cekStatus(nama, nilai) {
    if (nilai >= 75) {
        console.log(nama + ": LULUS");
    } else {
        console.log(nama + ": REMIDI");
    }
}

// 2. Uji coba dengan data siswa
cekStatus("Ahmad", 85);
cekStatus("Budi", 65);
Console Output

> Ahmad: LULUS

> Budi: REMIDI

Cara Kerja Program:

  1. Membuat fungsi bernama cekStatus yang menerima 2 data: nama dan nilai.
  2. Di dalam fungsi, logika if / else mengecek apakah nilainya 75 ke atas atau tidak.
  3. Saat cekStatus("Ahmad", 85) dipanggil, nilai Ahmad (85) memenuhi syarat (>= 75) sehingga tercetak **LULUS**.
