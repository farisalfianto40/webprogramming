5.1 Bootstrap Grid System & Layout Responsif

Konsep pembagian tata letak 12-kolom berbasis Flexbox serta penggunaan class breakpoint pada Framework Bootstrap.

01

Konsep Dasar Grid System & Breakpoint Bootstrap

Grid System Bootstrap menggunakan tata letak berbasis 12 kolom responsif. Komponen dasarnya terdiri dari .container, .row, dan class kolom .col-* beserta breakpoint responsifnya.

col- < 576px

Extra Small (HP)

col-sm- ≥ 576px

Small (HP Besar)

col-md- ≥ 768px

Medium (Tablet)

col-lg- ≥ 992px

Large (Desktop)

col-xl- ≥ 1200px

Extra Large

<!-- Bootstrap 3 Kolom Responsif -->
<div class="container">
  <div class="row g-3">
    <div class="col-12 col-md-4">
      <div class="p-3 bg-primary-subtle text-primary border border-primary-subtle rounded text-center">Kolom 1</div>
    </div>
    <div class="col-12 col-md-4">

    </div>
    <div class="col-12 col-md-4">
      <div class="p-3 bg-primary-subtle text-primary border border-primary-subtle rounded text-center">Kolom 3</div>
    </div>

</div>

Penjelasan Class Grid Bootstrap

  • container: Membungkus elemen dan memberikan padding horizontal.
  • row: Pembungkus baris wajib untuk menampung kolom-kolom.
  • col-12 col-md-4: Mengambil 12 kolom penuh (100% lebar) pada layar HP, dan 4 dari 12 kolom (1/3 lebar) pada layar medium (tablet/desktop) ke atas.
  • g-3: Mengatur tingkat jarak (*gutter*) antar kolom.
02

Proporsi Kolom (Pembagian 12 Kolom Bootstrap)

Bootstrap membagi area baris menjadi total 12 unit kolom. Kita dapat menentukan proporsi masing-masing elemen dengan mengkombinasikan angka hingga berjumlah total 12.

col-span.html 
<div class="row g-3">
  <!-- 8 Kolom (2/3 Lebar) -->
  <div class="col-8">
    <div class="p-3 bg-info-subtle text-info-emphasis border border-info-subtle rounded">
      Lebar 8 Kolom (col-8)
    </div>
  </div>

  <!-- 4 Kolom (1/3 Lebar) -->
  <div class="col-4">
    <div class="p-3 bg-warning-subtle text-warning-emphasis border border-warning-subtle rounded">
      Lebar 4 Kolom (col-4)
    </div>
  </div>
</div>

Aturan Pembagian Kolom Bootstrap

Pastikan total gabungan nilai angka kolom dalam satu baris (.row) bernilai 12 (misal: 8 + 4 = 12). Jika total melebihi 12, Bootstrap secara otomatis akan menurunkan elemen kolom berikutnya ke baris baru.

03

Studi Kasus: Layout Informasi Program Keahlian (Bootstrap Grid)

Penerapan Bootstrap Grid System untuk menyusun kartu informasi program keahlian yang terstruktur dan responsif.

jurusan-grid.html 
<!-- Judul Section -->
<div class="mb-3">
  <h5 class="fw-bold text-dark mb-1">Program Keahlian</h5>
  <p class="text-muted small">Bidang fokus pembelajaran siswa SMK SMTI Yogyakarta.</p>
</div>

<!-- Grid Bootstrap 2 Kolom Responsif -->
<div class="row g-3">
  <!-- Kolom 1 -->
  <div class="col-12 col-sm-6">
    <div class="p-3 bg-white border rounded shadow-sm h-100">
      <h6 class="fw-bold text-dark">Teknik Mekatronika</h6>
      <p class="text-muted small mb-0">Fokus pada integrasi sistem mekanik, kontrol PLC, dan pemrograman web industri.</p>
    </div>
  </div>

  <!-- Kolom 2 -->
  <div class="col-12 col-sm-6">
    <div class="p-3 bg-white border rounded shadow-sm h-100">

      <p class="text-muted small mb-0">Mempelajari proses operasional industri kimia dan pengendalian mutu bahan.</p>
    </div>
  </div>
</div>

Analisis Responsif Bootstrap

Penggunaan kombinasi class col-12 col-sm-6 membuat kartu jurusan secara intuitif memposisikan dirinya menumpuk penuh (1 kolom / col-12) pada layar smartphone, dan membagi diri menjadi 2 kolom berdampingan (col-sm-6) ketika dibuka di layar dengan lebar ≥ 576px.
