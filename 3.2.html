Modul 03 • CSS Layout

3.2 Layout Modern (Flexbox, Grid, & Position)

Teknik penyusunan tata letak halaman web secara fleksibel, responsif, dan terstruktur menggunakan CSS Modern.

01

CSS Flexbox (1-Dimensional Layout)

Flexbox digunakan untuk menyusun elemen dalam satu baris (horizontal) atau satu kolom (vertikal) secara dinamis.

flexbox.html 
<div class="flex-container">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
style.css 
.flex-container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 10px;
}

.item {
  padding: 12px 20px;
  background: #e0e7ff;
  border-radius: 6px;
}

Properti Utama Flexbox

  • display: flex: Mengaktifkan mode flexbox pada pembungkus (*container*).
  • justify-content: Mengatur perataan horizontal (flex-start, center, space-between).
  • align-items: Mengatur perataan vertikal (center, stretch).
  • gap: Memberikan jarak antar item fleksibel tanpa perlu margin manual.
02

CSS Grid (2-Dimensional Layout)

CSS Grid digunakan untuk menyusun tata letak dua dimensi yang kompleks (baris dan kolom sekaligus).

grid.html 
<div class="grid-container">
  <div class="box">A</div>
  <div class="box">B</div>
  <div class="box">C</div>
  <div class="box">D</div>
  <div class="box">E</div>
  <div class="box">F</div>
</div>
style.css 
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px;
}

.box {
  padding: 15px;
  background: #e0f2fe;
  text-align: center;
}

Penjelasan Properti Grid

  • display: grid: Mengaktifkan tata letak grid berbasis matriks.
  • grid-template-columns: Menentukan pembagian lebar kolom (contoh: repeat(3, 1fr) membagi tata letak menjadi 3 kolom berukuran sama rata).
  • gap: Mengatur jarak antar baris dan kolom grid secara presisi.
03

CSS Position (Relative, Absolute, Fixed)

Properti position mengatur penempatan elemen secara kustom, termasuk efek menumpuk (*overlay*) atau menempel (*sticky*).

position.html 
<div class="parent">
  Kartu Induk
  <div class="badge">Baru</div>
</div>
style.css 
.parent {
  position: relative;
  padding: 20px;
  background: #f8fafc;
}

.badge {
  position: absolute;
  top: 5px;
  right: 5px;
  background: #ef4444;
}
Hasil Tampilan Web
Kartu Induk Baru

Nilai-Nilai Position Utama

  • relative: Menjadi patokan acuan lokasi bagi elemen anak yang berposisi absolute.
  • absolute: Posisinya bebas diatur menggunakan nilai top, right, bottom, atau left relatif terhadap induknya.
  • fixed: Elemen dikunci relatif terhadap layar *browser*, tidak ikut berpindah saat halaman di-*scroll*.
04

Studi Kasus: Layout Kartu Produk Modern

Penerapan gabungan Flexbox, Grid, dan Position dalam pembuatan komponen kartu produk e-commerce yang presisi.

produk.html 
<div class="product-card">
  <span class="tag">DISKON</span>
  <img src="iphone.jpg" class="foto" alt="iPhone 17 Pro Max" />
  <h3 class="judul">iPhone 17 Pro Max</h3>
  <p class="harga">Rp 24.999.000</p>
</div>
style.css 
.product-card {
  position: relative;
  padding: 16px;
  border: 1px solid #cbd5e1;
  border-radius: 12px;
  background: #ffffff;
}

.tag {
  position: absolute;
  top: 12px;
  left: 12px;
  background: #ef4444;
  color: #ffffff;
  padding: 2px 8px;
  border-radius: 4px;
}

.foto {
  width: 100%;
  border-radius: 8px;
  margin-bottom: 12px;
}

Pembahasan Integrasi Layout Modern

  • Position Absolute Tag: Label DISKON diposisikan secara melayang di pojok kiri atas gambar produk dengan memanfaatkan acuan position: relative milik kartu.
  • Kontrol Lebar Gambar: Penggunaan width: 100% memastikan gambar merespons ukuran bingkai kartu secara proporsional.
