2.1 Tag Dasar & Semantik (Heading, Paragraph, Link, Image)

Fondasi penyusunan halaman web interaktif beserta penjelasan fungsi dan struktur dasarnya.

01

Pengertian & Struktur Dasar HTML

HTML (HyperText Markup Language) adalah bahasa standar yang digunakan untuk membuat dan menyusun halaman web. HTML menentukan struktur dan isi dari suatu halaman, seperti teks, gambar, tautan, dan tabel.

HyperText

Teks yang memiliki link (tautan) ke dokumen atau halaman web lain.

Markup Language

Bahasa yang menggunakan tag atau penanda untuk mengatur tampilan isi halaman.

Bukan Pemrograman

HTML adalah penanda struktur, tidak memiliki logika aritmatika/kondisional.

02

Heading (<h1> - <h6>)

Heading digunakan untuk mendefinisikan judul atau sub-judul pada halaman web. Penggunaan heading yang runtut mempermudah pembaca dan mesin pencari (SEO) memahami hirarki informasi.

heading.html 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8" />
    <title>Latihan Heading</title>
</head>
<body>
    <h1>Ini adalah heading 1</h1>
    <h2>Ini adalah heading 2</h2>
    <h3>Ini adalah heading 3</h3>
    <h4>Ini adalah heading 4</h4>
    <h5>Ini adalah heading 5</h5>
    <h6>Ini adalah heading 6</h6>
</body>
</html>

Penjelasan Materi Heading (Tingkat Hirarki & Fungsi)

Elemen heading menentukan struktur dokumen secara semantik. Sebaiknya tidak memilih tingkat heading hanya berdasarkan ukuran tampilannya, melainkan berdasarkan hirarki struktur konten:

  • H1 (<h1>): Judul utama halaman web. Hanya boleh ada satu tag <h1> per dokumen agar struktur SEO tetap optimal.
  • H2 (<h2>): Sub-judul bagian utama (Section) yang digunakan untuk membagi bab atau topik pembahasan besar.
  • H3 (<h3>): Sub-bagian dari <h2> yang dipakai untuk merinci rincian topik di bawah sub-bab.
  • H4 - H6 (<h4> - <h6>): Sub-hirarki tingkat lanjut untuk komponen kecil, widget, footnote, atau judul kartu modul.
03

Paragraph (<p>)

Tag <p> digunakan untuk mengelompokkan kalimat menjadi satu paragraf terstruktur.

paragraf.html 
<!DOCTYPE html>
<html lang="en">
<head>
    <title>Latihan Paragraf</title>
</head>
<body>
    <p>Ini adalah paragraf pertama dalam web.</p>
    <p>Paragraf kedua otomatis berjarak.</p>
</body>
</html>
http://localhost:5500/paragraf.html

Ini adalah paragraf pertama dalam web.

Paragraf kedua otomatis berjarak.

Penjelasan Materi Elemen Paragraf & Karakternya

Tag <p> merupakan salah satu tipe elemen Block-level. Sifat dan perilaku utamanya meliputi:

  • Auto-Margin: Browser secara otomatis menambahkan margin (jarak vertikal) sebelum dan sesudah tag <p> untuk memisahkan antar blok bacaan.
  • Line Wrapping: Teks panjang di dalam tag paragraf akan otomatis melipat turun ke baris baru ketika menyentuh batas lebar container/layar.
  • Penyatuan Spasi: HTML memangkas spasi ganda atau baris baru berlebih di dalam kode sumber menjadi satu spasi tunggal saja pada tampilan browser. Jika ingin pindah baris secara paksa tanpa membuat paragraf baru, gunakan tag <br>.
04

Hyperlink (<a>) & List (<ul>, <ol>)

Penggabungan tautan dan daftar item untuk membuat struktur navigasi dan pengelompokan data pada aplikasi web.

link.html 
<h1>Contoh Link</h1>
<a href="https://www.wikipedia.org" target="_blank">Wikipedia</a>
<a href="profil.html">File Lokal</a>

<h1>Contoh List Link</h1>
<ul>
    <li><a href="https://www.wikipedia.org" target="_blank">Wikipedia</a></li>
    <li><a href="profil.html">File Lokal</a></li>
</ul>
http://localhost:5500/link.html

Wikipedia File Lokal

Contoh List Link

  • Wikipedia
  • File Lokal

Penjelasan Materi Hyperlink & Struktur List

Hyperlink (<a>)

Membuka tautan antar dokumen web. Elemen ini membutuhkan atribut kunci:

  • href: Alamat tujuan (URL eksternal atau file lokal).
  • target="_blank": Membuka link di tab/jendela browser baru.
Daftar / List (<ul>, <ol>)

Menyajikan item berurutan atau tidak berurutan secara sistematis:

  • <ul>: Unordered List (daftar berpoin/bullet).
  • <ol>: Ordered List (daftar berurutan angka/abjad).
  • <li>: List Item (elemen isi dari daftar).
05

Image (<img>)

Tag <img> digunakan untuk menyisipkan gambar media visual ke dalam tata letak dokumen HTML.

image.html 
<!DOCTYPE html>
<html lang="id">
<head>
    <title>Latihan Image</title>
</head>
<body>
    <h1>Gambar Drone</h1>
    <img src="drone.jpg" alt="Foto Drone" width="300" />
</body>
</html>
http://localhost:5500/image.html

Gambar Drone

Penjelasan Materi Elemen Gambar & Atributnya

Tag <img> merupakan tipe elemen Inline (Self-Closing) yang tidak memerlukan tag penutup. Penggunaannya dikontrol oleh atribut-atribut berikut:

  • src (Source): Menyimpan jalur lokasi/file gambar, baik berupa direktori lokal maupun tautan URL eksternal.
  • alt (Alternate Text): Menampilkan teks pengganti jika file gagal dimuat sekaligus membantu aksesibilitas pembaca layar (screen reader).
  • width & height: Mengatur dimensi lebar dan tinggi gambar dalam piksel untuk menjaga kestabilan tata letak saat gambar dimuat.
06

Studi Kasus: Kartu Artikel Berita (Integrasi Semua Elemen)

Contoh penerapan nyata yang menggabungkan seluruh elemen dasar (Heading 1–3, Gambar, Paragraf, Daftar Unordered/Ordered, dan Hyperlink) dalam sebuah komponen Halaman Berita Teknologi.

artikel.html 
<h1>Portal Berita Teknologi</h1>

<img 
    src="robot.jpg" 
    alt="Robot Otomasi" 
    width="400" />

<h2>Perkembangan Industri Mekatronika 4.0</h2>

<p>
    Teknologi otomasi modern kini memanfaatkan integrasi antara sistem kontrol PLC, mikrokontroler, dan jaringan IoT untuk meningkatkan efisiensi industri secara signifikan.
</p>

<h3>Fitur Utama Sistem:</h3>
<ul>
    <li>Pemantauan Sensor Real-time</li>
    <li>Integrasi Cloud Firebase</li>
</ul>

<p>
    Pelajari selengkapnya di <a href="https://id.wikipedia.org" target="_blank">Artikel Wikipedia</a>.
</p>
http://localhost:5500/artikel.html

Analisis Integrasi Tag pada Studi Kasus

Pada struktur kode studi kasus di atas, seluruh tag disusun berdasarkan fungsionalitas dan hierarki semantik yang logis:

  • <h1>, <h2>, <h3>: Membagi judul portal utama (<h1>), judul topik berita (<h2>), dan judul daftar fitur (<h3>).
  • <img>: Menampilkan media header artikel dengan atribut alt untuk deskripsi aksesibilitas.
  • <p>: Menampung paragraf ringkasan konten berita agar mudah dibaca.
  • <ul> & <li>: Menyusun daftar poin fitur tanpa urutan nomor.
  • <a>: Menyediakan tautan rujukan luar yang dibuka pada tab baru lewat atribut target="_blank".
