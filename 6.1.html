Modul 6.1 • Tutorial Alur Kerja Git

Panduan Lengkap Git & GitHub

Langkah install, membuat repository, upload pertama kali, hingga mengunggah perubahan data.

01

Instalasi Aplikasi & Akun

  • Install Git: Unduh installer di git-scm.com dan install seperti biasa.
  • Buat Akun GitHub: Daftar akun gratis di github.com.
Terminal / PowerShell 
# Set identitas pengembang di komputer (Cukup 1x)
git config --global user.name "Nama Anda"
git config --global user.email "email@domain.com"
02

Simpan & Push Pertama Kali ke GitHub

Buat Repository baru di GitHub (biarkan kosong tanpa README), lalu jalankan urutan perintah berikut di terminal VS Code folder proyek Anda:

Terminal / PowerShell 
# 1. Inisialisasi folder proyek
git init

# 2. Tandai semua file proyek
git add .

# 3. Simpan catatan komit lokal
git commit -m "first commit"

# 4. Ubah nama branch utama
git branch -M main

# 5. Hubungkan ke URL repository GitHub Anda
git remote add origin https://github.com/USERNAME/NAMA-REPO.git

# 6. Upload data pertama kali (Browser akan minta login)
git push -u origin main
03

Upload Ketika Ada Perubahan Kode (Rutinitas)

Setiap kali Anda selesai mengedit file HTML/CSS/JS, jalankan 3 langkah cepat ini untuk memperbarui data di GitHub:

Terminal / PowerShell 
# Langkah 1: Tandai perubahan file baru
git add .

# Langkah 2: Simpan dengan pesan revisi
git commit -m "mengubah tampilan halaman utama"

# Langkah 3: Upload perubahan ke GitHub
git push
