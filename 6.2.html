Tutorial Hosting Gratis di GitHub Pages

Langkah mempublikasikan website HTML/CSS/JS agar dapat diakses publik secara online.

Syarat Wajib: Pastikan repository Anda di GitHub memiliki file bernama index.html di folder utama (root) sebagai halaman muka website.

2. Menyiapkan Pengaturan GitHub Pages

  1. Klik menu tab Settings di bagian atas.
  2. Pada menu sebelah kiri, pilih menu Pages.
  3. Pada bagian Branch, pilih main dan folder /(root), lalu simpan dengan mengeklik tombol Save.
